بالعربية

صُممت كَلِمات لتعمل محلياً. لا نطلب حساباً، ولا نشغّل تحليلات أو إعلانات، ولا نملك خادماً أو مزامنة تجمع بياناتك.

ما الذي يُحفظ على جهازك؟

  • يحفظ الموقع سجل الكلمات والتفضيلات في localStorage داخل متصفحك. تبقى تعيينات الموقع ومراجعاته منفصلة عن الامتداد.
  • يحفظ امتداد Chrome أو Firefox الملف المحلي في storage.local داخل المتصفح: المستوى، الاهتمامات، التعيينات، المراجعات، الكلمات المحفوظة، وإعدادات التذكير.
  • يُحتفظ بهذه البيانات حتى تحذفها أنت. يمكنك تصدير نسخة JSON، أو استخدام أدوات مسح البيانات في الموقع أو أطلس الامتداد لحذفها.

طلبات الشبكة الاختيارية

  • يستخدم الموقع خطوط WOFF2 محلية مضمّنة ولا يطلب خطوطاً خارجية.
  • التذكير في الموقع اختياري ويستخدم إشعار المتصفح، ولا يعمل إلا مع بقاء علامة تبويب كَلِمات مفتوحة. تذكير الامتداد منفصل ويستخدم إعداد منبّهات وإشعارات MV3 الخاص به.
  • في Chrome فقط، وعند ضغطك صراحةً على «بحث خارجي في القاموس»، وبعد منح إذن القاموس الاختياري، يُرسل مصطلح البحث المنقح إلى Wiktionary العربية. قد يعالج مزوّد القاموس معلومات اتصال الشبكة المعتادة. لا تُرسل التعيينات أو السجل أو الصفحات التي تزورها، ولا يُحفظ سجل البحث في ملفك. بحث القاموس في Firefox محلي. يستخدم نطق الامتداد افتراضياً صوتاً عربياً يصفه المتصفح بأنه محلي. يمكن السماح بالنطق عن بُعد من إعدادات الأطلس بعد الاطلاع على التنبيه؛ عندها قد يُرسل النص المنطوق إلى مزوّد النطق في Chrome أو Firefox. نطق الموقع يتبع المتصفح ونظام التشغيل، وقد يستخدم مزوّداً عبر الشبكة.

الحذف والدعم

التصدير والحذف متاحان من عناصر التحكم المخصصة. مسح بيانات الموقع يزيل حالة التعلّم arabic_words_state وحالة التعريف الأولي kalimat_onboarded وإعداد التذكير kalimat_reminder، ويحافظ على تفضيل المظهر kalimat_theme. يحاول مسح بيانات الامتداد حذف الملف وإيقاف التذكير بشكل مستقل. قد ينجح الحذف بينما يفشل إيقاف التذكير أو يتعذّر قراءة حالته؛ تعرض الواجهة النتيجة الجزئية أو غير المؤكدة، وكذلك المسح المؤقت غير المحفوظ. تختلف صيغة JSON للموقع عن صيغة الامتداد؛ استيراد الأطلس مخصص لبيانات الامتداد ولا ينقل بيانات الموقع تلقائياً. يمكنك طلب المساعدة عبر صفحة الدعم والمشكلات.

English summary

Kalimat is local-first. It has no account, analytics, advertising, backend, telemetry, or sync service.

Local data

  • The website keeps reading history and preferences in browser localStorage.
  • The Chrome and Firefox extensions keep the local profile in storage.local. Website and extension stores, assignments, and reviews remain separate.
  • Data is retained until you delete it. JSON export and clear-data controls are provided on the website and in the Atlas settings.

Optional network requests

  • The website uses bundled local WOFF2 fonts and makes no external font request.
  • The website reminder is an opt-in browser Notification that fires only while a Kalimat tab is open. The extension reminder remains a separate MV3 alarms/notifications setting.
  • On Chrome only, an explicit external-dictionary search with optional host permission sends only the normalized search term to Arabic Wiktionary. Wikimedia may process standard network connection metadata. No profile, history, visited-page data, cookies, or background requests are sent, and lookup history is not retained. Firefox dictionary lookup is local. Extension speech uses an Arabic voice reported as local by the browser by default. After the Atlas disclosure, you can opt in to remote speech, which may send spoken text to the browser speech provider on Chrome or Firefox. Website speech remains browser/OS dependent and may use a network provider.

Deletion and support

Use the website or Atlas controls to export or delete data. Website clear-data removes learning state arabic_words_state, onboarding kalimat_onboarded, and reminder settings kalimat_reminder while preserving the separate kalimat_theme preference. Extension clear-data attempts profile deletion and reminder disabling independently. Deletion may succeed while reminder disabling fails or its state is unreadable; the interface reports partial or unknown outcomes, including temporary unpersisted deletion. Website and extension JSON formats are distinct; Atlas imports extension JSON only, with no automatic website migration. Contact support through the GitHub issues page.
