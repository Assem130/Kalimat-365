بالعربية

صُممت كَلِمات لتعمل محلياً. لا نطلب حساباً، ولا نشغّل تحليلات أو إعلانات، ولا نملك خادماً أو مزامنة تجمع بياناتك.

ما الذي يُحفظ على جهازك؟

  • الموقع الرئيسي للتعريف بالامتداد وتثبيته. لا يقرأ سجل كلماتك ولا ينقله. يحفظ اختيار المظهر فقط في kalimat-support-theme. تبقى بيانات الموقع السابق في localStorage منفصلة عن الامتداد.
  • يحفظ امتداد Chrome أو Firefox الملف المحلي في storage.local داخل المتصفح: المستوى، الاهتمامات، التعيينات، المراجعات، الكلمات المحفوظة، وإعدادات التذكير.
  • يُحتفظ بهذه البيانات حتى تحذفها أنت. يمكنك تصدير نسخة JSON، أو استخدام أدوات مسح البيانات في الموقع أو أطلس الامتداد لحذفها.

طلبات الشبكة الاختيارية

  • يستخدم الموقع خطوط WOFF2 محلية مضمّنة ولا يطلب خطوطاً خارجية.
  • التذكير في الموقع اختياري ويستخدم إشعار المتصفح، ولا يعمل إلا مع بقاء علامة تبويب الموقع السابق مفتوحة. تذكير الامتداد منفصل ويستخدم إعداد منبّهات وإشعارات MV3 الخاص به.
  • في Chrome فقط، وعند ضغطك صراحةً على «بحث خارجي في القاموس»، وبعد منح إذن القاموس الاختياري، يُرسل مصطلح البحث المنقح إلى Wiktionary العربية. قد يعالج مزوّد القاموس معلومات اتصال الشبكة المعتادة. في البحث اليدوي لا تُرسل التعيينات أو السجل أو الصفحات التي تزورها، ولا يُحفظ سجل البحث في ملفك. بحث القاموس في Firefox محلي. يستخدم نطق الامتداد افتراضياً صوتاً عربياً يصفه المتصفح بأنه محلي. يمكن السماح بالنطق عن بُعد من إعدادات الأطلس بعد الاطلاع على التنبيه؛ عندها قد يُرسل النص المنطوق إلى مزوّد النطق في Chrome أو Firefox. نطق الموقع يتبع المتصفح ونظام التشغيل، وقد يستخدم مزوّداً عبر الشبكة.

المصادر اليومية في نسخة التطوير

هذه الميزة موجودة في نسخة التطوير الحالية، وليست ضمن إصدار المتجر 0.3.0 أو إصدار GitHub التجريبي 0.4.0 المنشورين وقت تحديث هذه الصفحة. تختلف الميزات بحسب النسخة المثبتة.

لا تعمل المصادر اليومية قبل تفعيلها ومنح إذن الوصول الاختياري إلى ويكيبيديا العربية وويكاموس العربية. تطلب النسخة نصوصًا عربية عامة مباشرة من Wikimedia، وقد ترسل الطلبات في الخلفية عند إعداد كلمة اليوم. تكشف الطلبات عنوان IP ومعلومات الاتصال المعتادة وعناوين عامة أو كلمات بحث مرتبطة بالموضوع. لا تُرسل كلماتك المحفوظة أو سجل قراءتك أو صفحات تصفحك أو ملفك المحلي، ولا تُرسل ملفات تعريف الارتباط مع هذه الطلبات.

تساعد مادة معجمية مضمّنة من ويكاموس ومن معجم اللغة العربية المعاصرة بصيغة LMF في الاختيار محليًا. مصدر مادة LMF هو سجل LINDAT المنشور باسم Driss Namly عام 2015، بترخيص CC BY-NC 4.0 ضمن الاستخدام غير التجاري لكَلِمات. لا ترسل قراءة هذه المادة طلبات إلى LINDAT أو ناشر المعجم. طلبات الاكتشاف عبر الإنترنت إلى Wikimedia منفصلة عن هذه البيانات المضمّنة.

تُحفظ اهتمامات المصادر والكلمات المعروفة والبطاقات المقبولة وتفاصيل مصادرها على جهازك. تدخل هذه البيانات في النسخة الاحتياطية للامتداد، وتُحذف عند مسح بياناته. يمكنك إيقاف المصادر من إعدادات الأطلس مع الاحتفاظ بالكلمات السابقة. المقتطفات الآلية غير مراجعة بشريًا. تبقى الكلمات السابقة متاحة دون اتصال، ولا تختار نسخة التطوير كلمة جديدة من قائمة ثابتة عند تعذّر الاكتشاف.

الحذف والدعم

التصدير والحذف متاحان من عناصر التحكم المخصصة. مسح بيانات الموقع يزيل حالة التعلّم arabic_words_state وحالة التعريف الأولي kalimat_onboarded وإعداد التذكير kalimat_reminder، ويحافظ على تفضيل المظهر kalimat_theme. يحاول مسح بيانات الامتداد حذف الملف وإيقاف التذكير بشكل مستقل. قد ينجح الحذف بينما يفشل إيقاف التذكير أو يتعذّر قراءة حالته؛ تعرض الواجهة النتيجة الجزئية أو غير المؤكدة، وكذلك المسح المؤقت غير المحفوظ. تختلف صيغة JSON للموقع عن صيغة الامتداد؛ استيراد الأطلس مخصص لبيانات الامتداد ولا ينقل بيانات الموقع تلقائياً. يمكنك طلب المساعدة عبر صفحة الدعم والمشكلات.

English summary

Kalimat is local-first. It has no account, analytics, advertising, backend, telemetry, or sync service.

Local data

  • The main website explains the extension and provides installation links. It does not read or transfer your word history. It stores only its appearance preference in kalimat-support-theme. The legacy website keeps its separate reading data in localStorage.
  • The Chrome and Firefox extensions keep the local profile in storage.local. Website and extension stores, assignments, and reviews remain separate.
  • Data is retained until you delete it. JSON export and clear-data controls are provided on the website and in the Atlas settings.

Optional network requests

  • The website uses bundled local WOFF2 fonts and makes no external font request.
  • The website reminder is an opt-in browser Notification that fires only while a legacy website tab is open. The extension reminder remains a separate MV3 alarms/notifications setting.
  • On Chrome only, an explicit external-dictionary search with optional host permission sends only the normalized search term to Arabic Wiktionary. Wikimedia may process standard network connection metadata. Manual dictionary lookup sends no profile, history, visited-page data, cookies, or background requests, and does not retain lookup history. Firefox dictionary lookup is local. Extension speech uses an Arabic voice reported as local by the browser by default. After the Atlas disclosure, you can opt in to remote speech, which may send spoken text to the browser speech provider on Chrome or Firefox. Website speech remains browser/OS dependent and may use a network provider.

Daily sources in the development version

This feature is present in the current development version. It is not included in the published store version 0.3.0 or GitHub beta 0.4.0 at the date of this policy. Available features depend on your installed version.

Daily sources remain off until you enable them and grant optional access to Arabic Wikipedia and Wiktionary. The development version requests public Arabic material directly from Wikimedia, including background requests when preparing a daily word. Requests disclose your IP address, ordinary connection metadata, and public titles or topic search terms. They do not transmit your saved words, reading history, visited pages, local profile, or browser cookies. Wikimedia handles requests under its own policies.

Bundled reference data from Arabic Wiktionary and the LMF Contemporary Arabic dictionary support local selection. The LMF data come from the LINDAT record by Driss Namly, 2015, under CC BY-NC 4.0 for Kalimat's non-commercial use. Reading the bundled LMF data sends no request to LINDAT or the dictionary publisher. Online Wikimedia discovery requests are separate from these bundled data.

Source interests, known-word exclusions, accepted cards, and their source details remain in local extension storage. They are included in extension backups and removed by clear-data. You can disable daily sources in Atlas settings without removing existing words. Automated excerpts are not human-reviewed. Previously stored words remain available offline. The development version does not substitute a fixed-list word when discovery is unavailable.

Deletion and support

Use the website or Atlas controls to export or delete data. Website clear-data removes learning state arabic_words_state, onboarding kalimat_onboarded, and reminder settings kalimat_reminder while preserving the separate kalimat_theme preference. Extension clear-data attempts profile deletion and reminder disabling independently. Deletion may succeed while reminder disabling fails or its state is unreadable; the interface reports partial or unknown outcomes, including temporary unpersisted deletion. Website and extension JSON formats are distinct; Atlas imports extension JSON only, with no automatic website migration. Contact support through the GitHub issues page.
